# ECLIPSE RECORD（エクリプス・レコード）

*月蝕の夜、封印された真実が目を覚ます。*

剣と魔法の世界を舞台に、探偵騎士団の一員として魔法犯罪を調査・推理するファンタジーRPG。
スマートフォンの縦画面を優先したブラウザゲームで、PWA（Progressive Web App）としてホーム画面に追加して遊べます。

## 主な特徴

- **調査×推理×バトルの一体型ループ**：事件現場での証拠収集・NPCへの聞き込み・簡易バトル・選択式推理を、1つの章の中で一通り体験できる
- **矛盾する証言**：警備員と学芸員、2人の目撃証言があえて食い違うように設計されており、推理の手がかりになる
- **タブ構成の事件簿**：概要／人物／証拠／証言／推理の5タブで、集めた情報を整理して確認できる
- **キャラクター育成タブ**：ステータス／装備／スキル／秘録／絆の5タブ。ドット絵のアクセサリー（指輪・ペンダント・ブローチ）を装備でき、ステータス変化が実際のバトルに反映される
- **絆システム**：会話・戦闘勝利・事件解決の節目でセレナとの絆ゲージが上昇し、関係性の変化が言葉で表現される
- **バトル演出**：戦闘開始・勝利・撤退のバナー演出、ドット絵の斬撃・回復エフェクト、レベルアップ・宝箱開封のイラスト演出、行動キャラのラウンジ（踏み込み）モーション、被弾フラッシュ、ターン順表示
- **AUTO・倍速機能**：周回や消化試合を快適にする自動戦闘・2倍速モード
- **ドット絵を中心としたビジュアル**：ホーム背景・ナビゲーションアイコン・キャラクターアバター・バトル敵キャラ・装備アイコン・一部のマップ背景にドット絵イラストを使用し、月・ゴシック建築を基調にした青紫×銀×金のダークファンタジー調デザインシステムで統一
- **情報が凝縮されたホーム画面**：Lv・EXPバー・ゴールド・魔晶石・スタミナ・通知・メール・ミッション・期間限定イベントバナーなど、スマホRPGらしい情報量を、装飾的すぎず視認性を保ったレイアウトで表示
- **ショップと経済ループ**：バトル・事件解決で得たゴールドを貯めて、ショップでアクセサリーを購入し、キャラクター育成画面で装備する、という一連の流れが実際に機能する
- **第2章への導線**：第1章クリア後、冒険マップから次章の短い導入会話と「今後登場する脅威」ティザー（忘却の竜・ルナディス／月の巫女・セレナス／黒き騎士・ヴォルク）を含むプレビュー画面に進める
- **PWA対応**：ホーム画面に追加してアプリのように起動可能。Service Workerによるオフラインキャッシュに対応
- **クラウド保存（任意）**：Firebaseを設定すると、複数端末でセーブデータを同期可能（未設定でも端末内保存だけで問題なく遊べる設計）

## ゲームシステム

### 探索・事件現場
王立美術館の展示室を舞台に、6ヶ所の調査ポイント（物的証拠4件・聞き込み2件）をタップして調べる。すべて調べると、事件簿に自動で証拠・証言が記録される。

### 冒険マップ
王立美術館（第1章）を含む6つのロケーションをノードとして表示。第1章クリアで「忘れられた回廊」（第2章）が解放される。各ノードにはドット絵またはイラストの背景サムネイルを表示。

### バトル
最大4人パーティを想定した設計（現在使用可能なのは主人公とセレナの2人）。コマンドは「攻撃／スキル／魔法／防御」（「アイテム／逃走」は今後の実装に向けてボタンのみ用意）。AUTO・倍速に対応。

### 事件簿・推理
集めた証拠・証言をもとに、選択式の推理問題に挑戦する。正解すると「事件解決」→専用のリザルト演出（経験値・ゴールド・推理評価ランクなどを時間差で表示）→事件解決の顛末が語られ、次章の伏線が提示される。

### キャラクター育成
主人公・セレナ・ノア・リュシア・黒衣のアルトの5人をキャラクター選択チップから切り替えて閲覧可能（ノア・リュシア・アルトは未加入）。ステータス（Lv・HP・MP・ATK・DEF・EXP）に加えて、装備（アクセサリーの着脱、実際のステータス・バトルに反映）、スキル一覧、秘録（条件で解放される裏設定）、絆（仲間との関係性ゲージ）を確認できる。

## 技術構成

- **フロントエンド**：Vanilla HTML / CSS / JavaScript（フレームワーク不使用、単一ファイル `index.html` で完結）
- **PWA**：Service Worker（`sw.js`）によるオフラインキャッシュ対応。`manifest.json` によりホーム画面への追加・スタンドアロン起動に対応
- **バックエンド**：任意でFirebase（Authentication・Firestore）によるクラウド保存に対応可能（`firebase-init.example.js` を参照。デフォルトでは無効）
- **ホスティング**：GitHub Pages等の静的ホスティングを想定

## 遊び方（ローカルで開く）

`index.html` をブラウザで直接開くだけで遊べます（インターネット接続はGoogle Fontsの読み込みのみに使用し、フォントが読み込めない場合も代替フォントで動作します）。

ただし、**Service Worker（オフラインキャッシュ）は `file://` では動作しません**。PWAとしての動作確認には、簡易サーバーを使ってください。

```bash
cd tsukikage-game
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## GitHub Pagesへの公開手順

1. このフォルダ（`tsukikage-game/` の中身一式）をGitHubリポジトリのルート、または `docs/` フォルダにアップロードする
2. リポジトリの **Settings → Pages** を開く
3. **Source** で対象のブランチとフォルダ（`/root` または `/docs`）を選択し、保存する
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` でアクセスできるようになる

GitHub PagesはHTTPS配信のため、Service Worker（PWA機能）もそのまま動作します。

**資材を更新した場合の注意**：`sw.js` 内の `CACHE_NAME` のバージョン番号を必ず上げてください。上げないと、訪問済みのユーザーのブラウザに古いキャッシュが残り、更新が反映されません。

## PWA（ホーム画面に追加）について

- iOS（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：メニュー →「ホーム画面に追加」／もしくは自動で表示されるインストールバナーから追加

ホーム画面に追加すると、ブラウザのアドレスバー等が表示されないスタンドアロン表示で起動します。オフライン時も、一度読み込んだ範囲（HTML・アイコン等）はキャッシュから表示されます（Google Fontsなど外部リソースはオンライン時のみ反映されます）。

## クラウド保存（Firebase・任意）

デフォルトでは、セーブデータは端末のブラウザ（localStorage）にのみ保存されます。複数端末での進行状況の共有や、ブラウザのデータ削除に備えたバックアップをしたい場合は、Firebaseによるクラウド保存を任意で追加できます。

1. [Firebaseコンソール](https://console.firebase.google.com)でプロジェクトを作成
2. Authentication → Sign-in method →「匿名」を有効化
3. Firestore Database を作成
4. `firebase-init.example.js` を `firebase-init.js` としてコピーし、自分のプロジェクトの設定値を入力
5. `index.html` の `<head>` 内、コメントアウトされている以下の行を有効化する

   ```html
   <script type="module" src="firebase-init.js"></script>
   ```

`firebase-init.js` が `window.TsukikageCloud`（`save` / `load` / `signInAnon`）を定義していれば、ゲーム側の設定画面から「クラウドに保存」「クラウドから復元」が使えるようになります。この設定をしなくても、ゲームはこれまで通り端末内保存のみで問題なく遊べます。

## 既知の制限事項・今後の展望

- 現在プレイできるのは第1章のみで、第2章「忘れられた回廊」は導入会話とプレビュー画面（「今後登場する脅威」ティザーを含む）のみの骨組み状態です
- ノア・エルフェン、リュシア、黒衣のアルトはキャラクター育成画面で閲覧できますが、まだ仲間として加入・バトル参加はできません
- バトルコマンドの「アイテム」「逃走」はボタンのみ用意されており、機能は未実装です
- ビジュアルはドット絵を中心に据えていますが、ストーリー会話・キャラクター育成の大きな顔ポートレート、王立美術館（探索画面）の背景、地下水路（マップの1ノード）は、対応するドット絵素材が無いため引き続きイラスト調の素材を使用しています
- UIボタンの見た目はCSSベースのデザインで統一しており、ドット絵のボタン素材そのもの（9-slice画像等）は組み込んでいません
- キャラクターの表情差分、立ち絵スチル風イラスト、床タイル・本棚・燭台・旗・柵などの装飾小物イラストは未使用です
- クラウド保存（Firebase）はデフォルトでは無効で、有効化には開発者側での追加設定が必要です
- タイトルロゴ・アプリアイコンは簡易的な生成物・切り出し素材で、正式なデザインアセットではありません
- ホーム画面・クエスト詳細・ショップ・冒険マップ・ストーリー会話・探索・推理画面は最新のUIデザイン参考画像に合わせて作り直していますが、事件簿の概要／人物タブ、バトル、キャラクター育成の各画面は、まだ同参考画像のレイアウト（装備の一覧レイアウトなど）には作り直していません
- 会話の選択肢は、現時点では第1章冒頭の1箇所にのみ実装されています。選んだ選択肢によって以降の章の展開が変わるような本格的な分岐（フラグ管理）は未実装です
- スタミナの「＋」ボタン、魔晶石（プレミア通貨）、お知らせ／メール／ミッションは、現時点では確認用のモーダルを表示するのみで、実際の消費・回復・進捗管理のロジックは未実装です

- **AUTO（自動送り）**：ボタンをONにすると、会話が一定間隔（約1.2〜2秒）で自動的に進むようになる。選択肢が表示されている間は自動送りが一時停止し、プレイヤーの選択を待つ
- **LOG（会話ログ）**：これまで表示した会話をさかのぼって確認できるモーダルを新設。章の会話が始まるたびにログはリセットされる
- **選択肢システムを新規実装**：第1章冒頭の会話に、プレイヤーが2択から応答を選べる場面を追加（「記憶ごと消えた、ということか。」／「誰かが嘘をついている可能性は？」）。選んだ選択肢に応じてセレナの返答が変化する。会話データに`choices`（選択肢と、それぞれの返答）を持たせるだけで他の会話にも同じ仕組みを追加できる汎用的な実装にした

### 第12回：推理画面に「根拠となる証拠を選ぶ」ステップを追加

UIデザイン参考画像の推理画面（選択肢に加えて「選択した証拠 3/3」を確認できる構成）に合わせて、推理の確定方法を作り変えました。

- **証拠選択ステップを新設**：これまでは4択の選択肢を選ぶだけで正誤判定していましたが、選択肢に加えて、根拠となる証拠・証言をチップから選ぶ操作を追加。「肖像画に残る魔力の残滓」「記憶魔法の紋章が刻まれた魔導具の欠片」「床の足跡（争った形跡がない）」の3点を選んだ状態で、正しい選択肢（記憶魔法による認識改竄）を選んで確定すると推理成功となる
